Thank you for your interest in contributing to TG BOT RPG! 🎉

## How to Help

1. **Fork the repository** — create your own copy of the project
2. **Create a branch** — `git checkout -b feature/your-feature-name`
3. **Develop** — make your changes
4. **Test** — ensure everything works
5. **Commit** — `git commit -m "Description of changes"`
6. **Push** — `git push origin feature/your-feature-name`
7. **Pull Request** — create a PR to the main branch

## Code Requirements

- Follow PEP 8
- Add docstrings to functions and classes
- Use English for code comments
- Use English for UI text

## Development Setup

```bash
# Install dev dependencies
pip install -r requirements-dev.txt

# Run linter
flake8 .

# Run formatter
black .
```

## Code Structure

```
handlers/       - Telegram command handlers
database/       - Database models and operations
assets/         - Graphic resources
config.py       - Configuration
main.py         - Entry point
```

## Report a Bug

Please create an Issue with a description of:
- What happened?
- How to reproduce it?
- Expected result
- Actual result

## Questions?

Create an Issue with the "question" tag or contact the developers.
